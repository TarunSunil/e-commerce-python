================================================================================
🎯 PROJECT OVERVIEW
================================================================================

This is a modern, microservices-based e-commerce platform with three main 
components: a React frontend, a Python FastAPI backend, and a machine learning 
recommender service. The application features user authentication, product 
browsing, shopping cart, order management, and AI-powered product 
recommendations.

🏗️ TECHNOLOGY STACK
================================================================================

FRONTEND (frontend/)
--------------------
- Framework: React 18.2 with TypeScript
- Build Tool: Vite
- Styling: TailwindCSS + PostCSS
- Routing: React Router DOM v6
- Animations: Framer Motion
- HTTP Client: Axios
- State Management: React Query (react-query)

BACKEND (backend/)
------------------
- Framework: FastAPI 0.110.0
- Server: Uvicorn (ASGI server)
- Database: PostgreSQL with SQLAlchemy 2.0 ORM
- Migrations: Alembic
- Authentication: JWT (python-jose) + Bcrypt (passlib), with 8-character minimum registration passwords and rate-limited auth routes
- Schema Validation: Pydantic v2

RECOMMENDER SERVICE (recommender/)
----------------------------------
- Framework: FastAPI 0.115.0+
- ML Library: scikit-learn (for similarity calculations)
- Algorithm: Optional content-based filtering using category similarity
- HTTP Client: Requests library

DATABASE
--------
- PostgreSQL with pgAdmin for management
- ORM: SQLAlchemy with declarative models

3. RECOMMENDER SERVICE (recommender/)
======================================

FILES
-----
- app.py - FastAPI service with two endpoints:
  * GET /recommend/{product_id} - Recommends similar products based on 
                                   category overlap
  * GET /recommend/user/{user_id} - Recommends based on user preferences 
                                    (or popularity)
- recommender.py - ContentBasedRecommender class with Jaccard similarity 
                   algorithm
- models.py - Pydantic models for data validation
- test_app.py - Unit tests for the recommender service

ALGORITHM
---------
- Content-Based Filtering: Uses Jaccard similarity coefficient
  * Formula: Similarity = |A ∩ B| / |A ∪ B|
  * Compares product categories to find similar items
  * Fallback to popularity (stock level) if no preferences exist

🔄 COMPLETE USER WORKFLOW
================================================================================

1. USER REGISTRATION/LOGIN FLOW
================================

Frontend (RegisterPage)
  ↓ POST /api/auth/register {name, email, password}
Backend (auth_router → auth_service.register)
  ↓ Hash password with Bcrypt
  ↓ Create User record in PostgreSQL
  ↓ Generate JWT token
  ↓ Return {token, userId, email, name, roles}
Frontend
  ↓ Store token in localStorage
  ↓ Set Authorization header for future requests
  ↓ Redirect to HomePage

================================================================================

2. BROWSE PRODUCTS FLOW
========================

Frontend (HomePage)
  ↓ GET /api/products?page=0&size=20&category=electronics&q=phone
Backend (products_router → product_service.get_products)
  ↓ Query PostgreSQL with filters (ILIKE search, category array contains)
  ↓ Apply pagination (OFFSET, LIMIT)
  ↓ Return Product[] array
Frontend
  ↓ Render ProductCard components with Framer Motion animations

================================================================================

3. VIEW PRODUCT DETAILS WITH RECOMMENDATIONS
=============================================

Frontend (ProductDetailPage)
  ↓ GET /api/products/{id}
Backend → PostgreSQL
  ↓ Return Product details
Frontend
  ↓ GET /api/recommend/{product_id}?limit=5
Backend (recommendations_router)
  ↓ Try proxy to Recommender Service
Recommender Service
  ↓ Fetch product from Backend
  ↓ Fetch all products from Backend
  ↓ Calculate Jaccard similarity on categories
  ↓ Return top 5 similar products
Backend (if proxy fails)
  ↓ Use fallback recommendation_service
Frontend
  ↓ Display recommended products

================================================================================

4. ADD TO CART FLOW
====================

Frontend (ProductDetailPage → Add to Cart button)
  ↓ POST /api/cart {productId, quantity}
  ↓ Authorization: Bearer <JWT>
Backend (cart_router → cart_service.add_to_cart)
  ↓ Verify JWT → extract userId
  ↓ Validate product exists
  ↓ Check stock availability
  ↓ Check if item already in cart
  ↓   If yes: Update quantity
  ↓   If no: Create new CartItem record
  ↓ Return CartItem
Frontend
  ↓ Update cart icon count

================================================================================

5. CHECKOUT & ORDER PLACEMENT
==============================

Frontend (CartPage → Checkout button)
  ↓ Navigate to CheckoutPage
  ↓ POST /api/orders
Backend (orders_router → order_service.create_order)
  ↓ Fetch user's cart items
  ↓ Validate stock for each item
  ↓ Create Order record
  ↓ Create OrderItem records (linked to Order)
  ↓ Deduct stock from Product table
  ↓ Clear user's cart
  ↓ BEGIN TRANSACTION → COMMIT
  ↓ Return Order with items
Frontend
  ↓ Show success message
  ↓ Redirect to Order History

🧠 RECOMMENDATION SYSTEM DETAILS
================================================================================

CONTENT-BASED FILTERING ALGORITHM
----------------------------------
- Similarity Metric: Jaccard Index
- Feature Used: Product categories (tags)
- Formula:
  Jaccard(A, B) = |A ∩ B| / |A ∪ B|
  Where A and B are sets of categories

EXAMPLE:
--------
Product A: ["electronics", "smartphone", "5G"]
Product B: ["electronics", "tablet", "5G"]

Intersection: {"electronics", "5G"}  → 2 items
Union: {"electronics", "smartphone", "5G", "tablet"}  → 4 items

Similarity = 2/4 = 0.5 (50% similar)

RECOMMENDATION STRATEGIES
-------------------------
1. Product-Based: Find N most similar products by category overlap
2. User-Based: Match products to user preferences (stored in user.preferences)
3. Popularity Fallback: Sort by stock level if no preferences exist

🔗 SERVICE COMMUNICATION
================================================================================

FRONTEND → BACKEND
------------------
- Protocol: HTTP/HTTPS with REST
- Authentication: JWT Bearer token in Authorization header
- Base URL: http://localhost:8080/api (configurable via VITE_API_URL)
- Request Format: JSON
- Response Format: JSON

BACKEND → DATABASE
------------------
- Protocol: PostgreSQL wire protocol
- Connection: SQLAlchemy ORM with psycopg2 driver
- Connection String: postgresql+psycopg2://user:pass@host:port/db
- Pooling: SQLAlchemy session pool

BACKEND → RECOMMENDER SERVICE
------------------------------
- Protocol: HTTP REST
- Method: Async HTTP calls with httpx library
- Fallback: Backend has local recommendation logic if service unavailable
- Timeout: 0.5s connect, 2.0s read
- Base URL: http://recommender:8000 (configurable via RECOMMENDER_URL)

RECOMMENDER → BACKEND
---------------------
- Protocol: HTTP REST with requests library
- Purpose: Fetch product data for recommendation calculations
- Endpoints Used: GET /api/products, GET /api/products/{id}

🎯 QUICK START GUIDE
================================================================================

1. PREREQUISITES
   - Python 3.10+
   - Node.js 18+
   - PostgreSQL 14+
   - Docker Desktop (optional, for containerized deployment)

2. SETUP BACKEND
   cd backend
   pip install -r requirements.txt
   # Create .env file with DATABASE_URL, JWT_SECRET, etc.
   alembic upgrade head
   uvicorn app.main:app --reload --port 8080

3. SETUP FRONTEND
   cd frontend
   npm install
   # Create .env file with VITE_API_URL
   npm run dev

4. SETUP RECOMMENDER
   cd recommender
   pip install -r requirements.txt
   uvicorn app:app --reload --port 8000

5. DOCKER DEPLOYMENT (EASIER)
   # From project root
   docker compose build
   docker compose up -d
   # Or use the PowerShell script
   .\start-services.ps1

6. ACCESS SERVICES
   - Frontend: http://localhost:3000
   - Backend API: http://localhost:8080/api
   - API Docs: http://localhost:8080/api/docs
   - Recommender: http://localhost:8000

7. CREATE ADMIN USER
   - Register through UI or use SQL:
     INSERT INTO users (id, email, password_hash, roles) 
     VALUES ('admin-id', 'admin@test.com', '<bcrypt_hash>', 
             ARRAY['USER', 'ADMIN']);
